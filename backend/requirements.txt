# nvidia2api 运行时依赖
#
# 为什么每个包都带**上界**：本项目对依赖的敏感度远高于一般 Web 应用——
#   cryptography  决定 Fernet 密文格式。`ChannelKey.api_key` / `Proxy.password`
#                 的存量密文一旦因大版本行为变化无法解密，等于上游 Key 全丢；
#   httpx         决定流式读取与代理连接语义（race_engine 的 read=None、
#                 AsyncClient 手工 __aenter__/__aexit__ 生命周期全押在它上面）；
#   Django        决定 ORM 条件 UPDATE、信号失效路径与 ASGI 线程池行为。
# 全 `>=` 意味着任何一次 `docker build` 都可能拉到未验证的新版本，
# 生产构建不可复现。上界按"当前实测通过版本所在大版本"设定；
# 升级时显式放开并跑全量测试（`cd backend && python -m pytest -q`）。
#
# 下界保持历史值（不破坏既有部署），上界收敛到实测大版本。
# 实测通过：Windows / Python 3.14 与 CI / Python 3.12。
#
# 测试依赖（pytest / pytest-django）已移到 requirements-dev.txt——
# 它们原先混在这里，被 Dockerfile 一并装进了生产镜像。
